
## miden::core::sys
| Procedure | Description |
| ----------- | ------------- |
| truncate_stack | Removes elements deep in the stack until the depth of the stack is exactly 16. The elements<br />are removed in such a way that the top 16 elements of the stack remain unchanged. If the stack<br />would otherwise contain more than 16 elements at the end of execution, then adding a call to this<br />function at the end will reduce the size of the public inputs that are shared with the verifier.<br /><br />Input: Stack with 16 or more elements.<br />Output: Stack with only the original top 16 elements.<br /><br />Cycles: 17 + 11 * overflow_words, where `overflow_words` is the number of words needed to drop.<br /> |
| drop_stack_top | Drops four words from the top of the stack.<br /> |
| build_proof_request_key | Computes the advice-map key addressing a proof package under an expected verifier identity.<br /><br />The v2 key is the domain-tagged hash of `claim_commitment ‖ expected_verifier` (one Eidos<br />block, so a single compression with no memory). It is a lookup address, not a trust anchor: the<br />verifier re-checks the retrieved package against its statement. Both inputs are program-owned:<br />the caller supplies its expected identity, committing to relation, entry key, and configuration,<br />and obtains the claim commitment from an authenticated verifier output or its own computation.<br />An implementation root or `procref` procedure key alone is not a verifier identity. Computing<br />this key does not authorize the identity or its configuration, or settle deferred obligations.<br />Mirrors `miden_core::program::proof_request_key`.<br /><br />Inputs:  [EXPECTED_VERIFIER, CLAIM_COMMITMENT, ...]<br />Outputs: [PROOF_REQUEST_KEY, ...]<br /> |
