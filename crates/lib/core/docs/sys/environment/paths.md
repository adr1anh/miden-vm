Selective membership and implementation upgrades in typed binary environments.<br /><br />A binding descriptor occupies twelve aligned elements:<br />`[leaf_label: word, implementation: word, path_ptr, path_len, 0, 0]`.<br />Its path contains `path_len` aligned eight-element records, ordered from the leaf's parent<br />toward the root. A record is `[kind, selector, 0, 0, payload: word]`:<br />- `kind = 0`: an Env ancestor; payload is its label and selector must be zero.<br />- `kind = 1`: a Merkle ancestor; payload is the sibling commitment and selector is zero<br />when the selected child is left, or one when it is right.<br /><br />A zero-length path opens a Mast directly at the root. List ancestors are not supported by<br />this binary-path format. Namespace derivation starts at the fixed initial namespace and<br />visits Env labels from root to leaf. Collection edges preserve the namespace.<br /><br />These procedures authenticate one occurrence. The caller must authorize the supplied root;<br />selective membership does not establish global procedure-key uniqueness or code availability.<br /><br />Cycle counts are raw VM operations on successful paths, including inlined bodies and local<br />frame setup/cleanup. They exclude control rows, block framing, padding, retained invocation<br />boundaries, and host/chiplet work. In the formulas, `e` and `m` count Env and Merkle records;<br />`z` is 1 for an empty path and 0 otherwise, counting the nop executed by each skipped loop.<br />
