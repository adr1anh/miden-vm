# PR08: Preserve keyed replay cuts and expose actual runtime debug frames

A one-row fragment could snapshot an ordinary cleanup block as its outer root END, skipping the block and requesting a missing keyed event. Snapshot capture now uses the prepared keyed-transition marker; ordinary block rows retain their executing continuation. Tests exercise invocation/return cuts, source matrices at sizes 1/3, mixed normal/SYS cache counts and malformed opening/forest/root IDs.

A separate runtime debug API exposes actual Entry/Invoke activations, requested K, resolved D, opening and native-use identity independently of source-frame inference. Small transient markers reference the existing session, reserve before publication and disappear on real returns. Pending work and source inline rows create no runtime activation. Native clones retain diagnostic identities; replay projection and serialization omit them without new authority or wire fields. Ordinary trace capture avoids cloning discarded sidecars.

The shared authenticated fixture accepts arbitrary root programs, and the private relocation fixture covers prefixes 0/8/16, serialized contexts, executable first cuts and sentinels through the actual writer. This synthetic-prefix test is reviewed but unrun; it does not establish relation rejection.
